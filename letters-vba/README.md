# خطوات التركيب (مرة واحدة)

1. انسخ الملف الأصلي احتياطيًا، ثم افتح `تسلسل أرقام الخطابات.xlsm`.
2. فعّل: ملف ← خيارات ← مركز التوثيق ← إعدادات مركز التوثيق ← إعدادات الماكرو ← **الثقة في الوصول إلى نموذج كائن مشروع VBA**.
3. اضغط `Alt+F11` ← ملف ← استيراد ملف ← اختر `modLetters.bas`.
4. ضع المؤشر داخل `SetupLetters` واضغط `F5`. ينشئ النافذة `frmLetters` والزر "إدخال / بحث" في الصف الأول.
5. احفظ بصيغة xlsm. يمكنك بعدها إلغاء خيار الثقة في الخطوة 2.

الزر يوضع بعد آخر عمود مستخدم في الصف 1؛ إن لم يكن موضعه مناسبًا اسحبه بالفأرة.
